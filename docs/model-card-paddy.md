## Paddy model (v1)

Generated by `notebooks/paddy_training.ipynb` on 2026-10-26. Every number is from photos the model and its calibration never saw.

> **Read this first.** On the held-out test split the model is 98.4% accurate, but those photos come from the same three datasets it trained on. With a whole dataset held out (the [table at the end](#leave-one-dataset-out)) it is 9–37% accurate, with up to 43% confident wrong answers: each disease comes mostly from one dataset, so the model partly learned each dataset's camera, background and light. A farmer's phone in a new district is the held-out case, so the app labels every paddy result "পরীক্ষামূলক: নতুন এলাকার ছবিতে এখনো নির্ভরযোগ্য নয়" and offers the officer on every result. The next step is 20–30 officer-labelled photos per disease from farmers' own fields.
