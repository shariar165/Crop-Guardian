# Paddy parity fixtures

Reference outputs from `notebooks/paddy_training.ipynb` for `parity.test.ts`, in the same format as `../parity/README.md`: 12 photos (4 healthy, 4 diseased, 4 of narrow brown spot, which the model never saw) and `expected.json` with the notebook's logits and decisions.

The notebook's `paddy_export.zip` fills this folder when unzipped at the repo root. Until then `expected.json` is empty and the paddy parity test is skipped.
